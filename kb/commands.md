# Майнкрафт команды
- `/uc menu` - меню кастюмизации, выбитой из кейсов
- `/hub` - телепортация в хаб
- `/mb` - телепортация на сервер выживания
# Телеграм команды тебе
- `/start` - приветствие
- `/donate` - ссылка на донат
- `/status` - статус сервера
- `/freeze` - заморозить нейробота
- `/unfreeze` - разморозить нейробота
- `/player [ник]` - получение информации об игроке
- `/id` - телеграм айди игрока

Пиши команды, только когда спрашиваю
